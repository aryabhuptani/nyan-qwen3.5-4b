# Reproducing catgirl_v1

This demo uses a **learned activation recipe for the pinned 4-bit MLX Qwen3.5-4B model**. It changes 4,096 MLP coordinates with paired gains and additive amounts. Native model weights stay unchanged. This is an optimized intervention, not evidence that each coordinate is an independently understood “catgirl neuron.”

The frozen artifact is [candidates/catgirl_v1.json](candidates/catgirl_v1.json). Its model is `mlx-community/Qwen3.5-4B-4bit`, revision `0e7ffd5c629ef7719d4cbc04069232580bfa9d9c`. Do not substitute Qwen3-4B, Qwen3-8B, or BF16 weights and expect the same output. This recipe's numeric additive amounts were optimized on that quantized model.

## Setup

Run from the repository root on an Apple Silicon Mac. The experiments used Python 3.12 and the exact package versions in [requirements.txt](requirements.txt), including MLX 0.32.4 and MLX-LM 0.32.2.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r catgirl/requirements.txt
```

Validate the artifact without loading MLX, downloading weights, or running the GPU:

```sh
.venv/bin/python catgirl/demo.py --check-only
```

Expected integrity values:

```text
unique neuron coordinates: 4096
intervention specifications: 8192
neuron recipe SHA256: 52e2a89494d3f464e0bbacbcefad47f2b9c47a710ddaa98bcd04ca2dd30b8327
```

The first actual run uses the original pinned snapshot directory if it exists, otherwise downloads the exact revision through Hugging Face. Use `--cache-dir PATH` to choose a download cache. Allow disk space for the model and environment; the CPU integrity check does not download either.

## Run a conversation

```sh
.venv/bin/python catgirl/demo.py
```

Or provide reproducible turns and save a new transcript:

```sh
.venv/bin/python catgirl/demo.py \
  --prompt "I have had a tiring day. Suggest a relaxing evening that costs almost nothing." \
  --prompt "Now help me plan a small herb garden on a windowsill." \
  --prompt "What would you change if the window only gets morning sun?" \
  --max-tokens 384 \
  --transcript /tmp/catgirl-v1-demo.jsonl
```

Use a new transcript filename for every run. The CLI refuses to overwrite an existing file. Interactive `/reset` begins a new conversation and permits one new bootstrap; `/quit` exits. Repeated `--prompt` arguments are ordinary user messages, not commands.

For a matched neutral-model comparison, run the same prompts with `--baseline` and a different transcript filename. Both paths use the frozen decoding: greedy temperature 0, seed 42, repetition penalty 1.1, and repetition context 128. The generic repetition penalty also applies to the baseline. Transcript records include the actual messages, effective intervention scope, model revision, package metadata, and output budgets.

## Exact intervention protocol

The runtime system message is only:

```text
You are a helpful assistant.
```

No catgirl instruction, Mika introduction, or assistant answer prefix is injected at runtime. The introduction is generated by the model under the numeric activation intervention. Training did use explicit persona target answers; the optimized recipe can encode that learned introduction.

At each affected layer, the neuron vector is the intermediate MLP activation immediately before `down_proj`:

```text
h = silu(gate_proj(x)) * up_proj(x)
h[neuron] = h[neuron] * factor + amount
```

Both entries for a coordinate must be applied. Indices are zero based. The raw `amount` values in the frozen artifact take precedence over its descriptive residual-relative `dose` values, so recalibrating local residual medians does not rescale this recipe.

On the first reply only, apply the recipe for **20 answer-prediction positions**. Position 1 is the final prompt-template token predicting the first answer token. All earlier prompt positions have scale 0. From prediction position 21 onward, both gain offsets and additive offsets have scale 0.

On every later conversation turn, apply an empty neuron recipe. Preserve the actual generated assistant replies in conversation history. The runner creates fresh generation caches each turn, so later persistence comes from conversation text rather than reuse of modified first-turn KV state. Steering is cleared after each completed generation. Reapplying the introduction on every turn is a different protocol and previously caused repeated introductions and poor follow-up continuity.

## What to claim

Treat this as a frozen experimental activation recipe. Read the artifact's `known_limits`, `verified_evidence`, and validation status before quoting success rates. Its discovery evidence includes useful short-task behavior and a conversation that retained identity after a long archive was added. That does not establish universal prompt robustness, reliable cold-start persona induction at every context length, or flawless factual, arithmetic, and formatting behavior.

The demo does not train or tune anything. It also does not execute the reserved evaluation batteries. For exact benchmark prompts, budgets, and human judgments, use the separately recorded evaluation artifacts rather than inferring a benchmark result from this example conversation.
