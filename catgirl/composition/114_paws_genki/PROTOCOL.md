# Study114: fresh replication of an unexpected Paws × Genki effect

This is a new, explicitly post-selection study. Study113's five primary composition hypotheses failed their practical screens. Its full factorial grid unexpectedly showed performed feline vocalization in 11/12 Paws+Genki replies, versus 1/12 base, 2/12 Paws and 1/12 Genki. We selected this candidate after seeing those results. These observations are discovery evidence, not confirmation. Study113's reserved confirmation prompts remain unused under its original rule.

## Fixed intervention and new cases

Use the same pinned original BF16 Qwen3.5-4B revision, normalization, four-coordinate catgirl base, female first16/prefill schedule, greedy decoding, 192-token limit, seed42 and repetition settings as113. Paws L23N4769 stays at normalized +.4, Genki L13N4810 at +.8; both apply throughout input and generation. No dose fitting or optimization occurs in114. The additional Animal sounds coordinate is absent. The base already includes cat-related coordinates; this is not a two-neuron intervention on an unsteered model.

A fresh case author, blind to outputs, supplies 12 new neutral English prompts in six families of two. No target role, affection or sound request is included. The author checks prior cases for reuse. All cases, methods, sources, controls, predictions, analysis and review code are frozen and pushed before114 inference. Case lengths and generation limits will be reported; these are independent short replies, not long-context or persistence tests.

Eight conditions use identical full messages: base, Paws, Genki, Paws+Genki, and four random pairs. Thus96 replies are required. Random controls use four distinct uniformly sampled coordinates in each corresponding layer, selected with Python random.Random(114) before114 outputs, excluding known original/modifier coordinates. Each pair receives normalized +.4 at layer23 and +.8 at layer13 with the same base and timing. Per-layer requested residual perturbation norms are matched through the unchanged published normalization and actual down-projection column norms. This does not match native activation percentiles, neuron functions, or downstream nonlinear effects. All four controls are retained regardless of results; no claim about the full random-neuron population follows from four pairs.

## Predictions and endpoints

Primary behavioral endpoint is assistant-performed feline vocalization, using the unchanged113 rubric: own-voice meow/mew/nya/purr or clear equivalents, excluding descriptions and quoted characters. The broader sound category is named explicitly; a mew is not silently called a literal occurrence of "meow". The other13 ratings, including cat/female role, coherence and integrated behavior, are descriptive and remain separate. Capability loss is not an acceptance gate.

Quantitative forecasts are fixed statistical extrapolations from113, not fresh agent claims about atlas meanings: for the four canonical conditions use (k+.5)/(12+1), with k=1,2,1,11 respectively. Random-pair predictions use the base rate (1+.5)/13 because no random-pair outcomes have been observed. Preserve all eight predictions and score per-condition case-level Brier loss. We expect the pair to exceed both singles and the average random control. These forecasts were informed by candidate selection and do not test description-only prediction.

## Analysis and review

Two fresh condition-masked reviews rate every reply. Randomly shuffle item order independently between reviewers; neither sees conditions, sources, forecasts, prior outcomes, or the other review. A fresh third masked reviewer resolves disputed or uncertain cells. Preserve every original0/1/null judgment, evidence, label hash and null sensitivity. Shared agent/rubric errors remain a limitation; these are not independent human gold labels.

Report all eight condition rates and all14 features with explicit unknown denominators. Main four-cell contrasts use the shared complete cases: p00,p10,p01,p11; pair minus each single/base/better single; interaction p11−p10−p01+p00. The specificity contrast is computed within each prompt as pair minus the mean of all four random-pair labels, requiring all five labels known. Report each random pair separately as well. Use paired prompt bootstrap percentile95% intervals, 5,000 draws and seed114; recompute the better-single maximum inside each draw. Preserve every family, including those with no complete cases.

There are two planned two-sided exact sign-flip tests: four-cell interaction, and pair-minus-average-random. Apply fixed-family Holm adjustment across both even if one is untestable. Their sign-exchangeability assumptions and this small convenience prompt sample limit inference. Report point estimates, intervals, adjusted p-values and original-reviewer sensitivity; do not equate a small p-value with a natural mechanism or arbitrary-prompt generalization. A practical increase of at least3/12 over each single with positive direction under both original reviewers would repeat the113 practical effect size criterion, not establish global reliability.

No further search, re-selection, dose change, dropped control or alternative endpoint will replace these tests. Literal sound vocabulary, boilerplate, coherence and role tradeoffs may be described separately. All failures remain part of the result. A successful replication would establish a bounded causal composition effect for these settings, not a minimal circuit, natural semantic coding, or validation of Goodfire's model-wide Already Clean hypothesis. The original113 prospective atlas comparison is reported separately, including its failures.
