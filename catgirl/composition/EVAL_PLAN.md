# Native neuron composition evaluation

This phase characterizes individual published native coordinates and intentional small compositions. It excludes the earlier learned 4096-coordinate recipe and supervised output training. Capabilities are descriptive; the primary target is reproducible constituent effects that survive together in an intentional composition without degeneration. Feline identity remains one measured dimension.

## Discovery comparisons

Compare baseline, each single at its prespecified doses, and same-layer/sign/dose random controls on the same neutral discovery prompts. Score each response along separate dimensions: female identity, feline identity, non-feline animal identity, cute register, maid/service role, pirate role, sage role, unicorn role, and other semantic contamination. A discussion of cats is different from being a catlike assistant. A feminine name alone is weaker than an explicit female self-description. A single cute token is weaker than sustained register.

Use identity/embodiment grades 0 absent, 1 ambiguous or decorative, 2 explicit self-attributed role consistent with the response. Use style grades 0 absent, 1 occasional, 2 sustained. Record prompt usefulness 0 unusable, 1 partial, 2 useful; exact instruction checks separately. Record degeneration, repeated spans, contradictions, refusals, and output truncation separately. Do not equate missing persona cues in a technical body with a demonstrated identity denial.

Before generating any pair or triple, write a hypothesis entry containing parent singles, exact doses, expected trait addition or suppression, expected interference, and an explicit failure criterion. Compare each composition to its constituent singles and matched baseline. Preserve null and antagonistic outcomes. Do not infer interaction from different prompts or decoding. An observed combination improvement is a useful empirical composition; it is not proof of an independent causal mechanism.

## Final evaluation

Freeze a small final set of recipes and evaluate baseline, chosen singles, pairs, and triples on all twelve sealed cases using identical decoding and task budgets. Run actual assistant outputs in conversation history. Record whether interventions apply to every turn or only the first; do not silently change timing. Grade task-visible overt persona separately from identity elicited by neutral probes. For long answers report cues by thirds, completion, and any actual identity reversion; no ear-action quota is imposed.

Report denominators: eleven persona-applicable cases, with the format case scored separately. For the conversation also report each turn and the final identity probe. Give exact-format and capability results descriptively. Primary scientific acceptance is that both preregistered constituent effects survive together on neutral heldout prompts without degeneration, with scope and negative cases stated plainly. A coherent pirate plus mascot or cute combination, or a unicorn combination, is valuable even without feline identity. Measure breadth, assistant embodiment, conversational persistence, and semantic contamination separately. A lexical cat topic or one identity-only success is not a general catgirl persona.
